# Anim3D

A lightweight, high-performance 3D animation and rendering engine built for real-time keyframing and mesh deformation.

## Features

- **Viewport & Scene Graph:** Interactive 3D camera controls and node hierarchy.
- **Keyframe Sequencing:** Timeline-based property animation for position, rotation, and scale.
- **Shading & Lighting:** Basic PBR (Physically Based Rendering) pipeline.
- **Export Formats:** Support for exporting animations to GLTF/GLB.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher) or a standard C++20 compiler setup.
- WebGL 2.0 / WebGPU enabled browser (if building for web).

### Installation

```bash
git clone [https://github.com/your-username/anim3d.git](https://github.com/your-username/anim3d.git)
cd anim3d
npm install
npm run dev
